# hard cap 256, RAY_TRACING_LIGHT_COUNT_MAXIMUM), so its reference silently drops lights here. Per fixed view:
# ReSTIR PT + RR (real time), the engine path tracer at the 256-light grid cap, and NvRTX's RTXDI path tracer
